# PRD: THE CLIMB TOUR 2026

## 1. 배경 & 문제

꽉크루는 2026년 5월 10일에 강남권 더클라임 6개 지점을 하루에 도는 "강남권 더클 뿌수기 대회"를 연다. 30~50명 규모의 참가자가 동시에 6개 지점을 이동하며 카테고리별 풀이 갯수를 기록해야 하는데, 다음 문제가 있다:

- **수기 집계 불가능**: 종이/구글 시트로는 실시간 순위 추적 불가
- **혼란 위험**: 참가자가 본인이 어느 카테고리인지·뭘 풀어야 하는지 헷갈림
- **세팅 변경 대응**: 세팅이 자주 바뀌는 더클라임 특성상 그레이드별 갯수가 대회 직전까지 계속 변동
- **운영진도 참가**: 운영진이 별도 자리에 앉아 관리할 수 없음. 본인도 뛰면서 운영해야 함

## 2. 목표

### 사용자 목표

- **참가자**: 본인 카테고리·동선 확인 → 풀이 기록 → 순위 확인 (모바일에서 한 손으로)
- **운영진(어드민)**: 지점/벽/그레이드 갯수 사전 입력, 당일 시간·공지 동적 조정, 결과 집계

### 비즈니스 목표

- 대회 당일 운영 부담 최소화 (운영진이 뛰면서도 폰으로 즉시 대응)
- 참가자 만족도 ↑ (헷갈리지 않는 룰, 공정한 채점)
- 향후 시리즈화 가능한 시스템 (매년 / 다른 지역 확장)

## 3. 사용자 페르소나

### 참가자 A — "처음 참가하는 게스트"

- 크루원 친구의 초대로 처음 참가
- 본인이 어느 카테고리인지 모름 → 가이드가 명확해야 함
- 폰으로만 사용. 데이터 통신 환경이 지점마다 다름 (지하층 약함)
- 풀이하면서 짧은 시간에 빠르게 입력해야 함

### 참가자 B — "익숙한 크루원"

- 매주 운동하는 핵심 크루원
- 본인 실력 정확히 알고 있음
- 순위 경쟁에 진심
- 다른 사람과 비교하면서 페이스 조절

### 운영진 — "본인도 뛰면서 운영하는 크루장"

- 30명 이상 참가자 신청·입금 관리
- 5/9까지 6개 지점 모든 벽의 갯수 정확히 입력
- 당일 양재점 사람 많아서 시간 늘리는 등 즉석 대응
- 결과 집계 및 시상자 확정

## 4. 핵심 기능

### F1. 카카오 로그인 + 참가 신청

- 카카오 OAuth로 간편 로그인
- 평소 푸는 색 (보라/핑크/빨강) 선택
- 카테고리 (상급/중급/초급) 선택 (핑크·빨강일 때만 두 옵션)
- 참가 유형 (크루원/게스트)
- 약관 동의 (환불 불가, 양심 채점, 횟수권/개월권 등)

### F2. 풀이 기록

- 본인 카테고리에 해당하는 색만 입력 (상급=빨강, 중급=파랑, 초급=초록)
- 지점 → 벽 → 본인이 푼 갯수 입력
- +/− 카운터 + 직접 숫자 입력
- 자동 저장 (입력 직후)
- 본인 진행률 실시간 표시

### F3. 대시보드

- 본인 진행 상황 (완등 비율, 부문 내 순위)
- 부문별 순위 (상급 / 중급 / 초급 — 3개 탭)
- 운영진 공지 배너
- 시간표 (본인 다음 일정)
- 30초 자동 갱신 (페이지 활성 시만)

### F4. 어드민 모드

- 권한 보유자만 헤더 토글로 진입
- 지점/벽 추가·수정·비활성화
- 그레이드별 갯수 입력
- 대회 메타 (일정·시간·점심) 동적 조정
- 텍스트 정의 (도전 그레이드 정의·핑크 가이드 등) 편집
- 참가자 입금 확인·삭제
- 팀 편성 (시작 벽 분산용)
- 결과 집계·CSV 다운로드
- 공지 즉시 입력

## 5. 비기능 요구사항

### 성능

- 페이지 로드 < 2초 (LTE 환경)
- 풀이 입력 → 저장 < 500ms
- 대시보드 갱신 폴링 30초 (피크 시 동시 50명 = 분당 100 요청, Supabase 무료 플랜 한도 내)

### 가용성

- 더클라임 지하층 같은 약한 통신 환경 대응
- 네트워크 실패 시 로컬 저장 후 복귀 시 동기화 (선택사항, MVP 후)

### 모바일 우선

- 모든 터치 영역 ≥ 44x44px
- iOS Safari, Android Chrome 호환
- 한 손 조작 가능 (주요 액션 화면 하단 또는 엄지 닿는 곳)

### 보안

- 카테고리·풀이 검증은 서버 사이드 필수 (클라이언트만 신뢰 X)
- 어드민 API는 권한 가드 통과 필수
- 참가자 카카오 닉네임은 표시명으로 사용 안 함 (별도 입력)

## 6. 비범위 (이번 버전에서 제외)

- 사진/영상 인증 — 양심 채점이 컨셉
- 결제 시스템 — 입금 + 어드민 수동 확인
- 실시간 WebSocket — 폴링으로 충분
- 푸시 알림 — 카카오톡 단톡방으로 충분
- 다국어 — 한국어만
- PWA / 앱 설치 — 웹으로 충분

## 7. 성공 지표

### 정량

- 신청자 ≥ 30명
- 신청 → 입금 완료율 ≥ 90%
- 대회 당일 풀이 입력 완료율 ≥ 95% (입금자 대비)
- 대시보드 갱신 평균 응답 < 800ms

### 정성

- 참가자 후기에서 "헷갈렸다" 언급 < 3건
- 운영진 당일 "버그/장애로 멈춤" 0건
- 다음 시즌 재개최 의향 ≥ 80%

## 10. 결정된 사항 / 미결정 사항

### 결정됨 ✓

- 시상: 부문별 1등 3명 (상급 1, 중급 1, 초급 1). 상금은 참가비 전액(N × 10,000원)을 3등분하여 배분
- 상금 배분 방식: 단순 균등 분배 (예: 30명 참가 → 30만원 → 부문별 10만원)
- 카테고리 매핑은 "1~2단계 낮게" (본인 양심 선택)
- 인증: 양심 채점, 사진/영상 X
- 이용권: 횟수권 / 개월권 (일일권 불가)
- 환불 불가
- 모두 같은 지점·시간 시작, 팀별 첫 시작 벽만 분산

### 미결정 ⚠

- 시작 시각 (참가 인원 확정 후)
- 점심 시간 / 점심 장소
- 지점별 체류 시간 (혼잡도 따라 어드민 조정)
- 정확한 참가비 입금 계좌
- 게스트 동반자 수 제한 여부
