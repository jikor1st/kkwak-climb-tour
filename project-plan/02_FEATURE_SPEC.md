# 기능 상세 명세

## 페이지 / 라우트 구조

```
/                          # 랜딩 (공개)
/login                     # 카카오 로그인
/signup                    # 참가 신청 (로그인 필요)
/signup/complete           # 신청 완료 / 대기 화면
/input                     # 풀이 기록 (참가자만)
/dashboard                 # 대시보드 (참가자만)
/admin/walls               # 지점/벽 관리 (어드민만)
/admin/time                # 시간 조정
/admin/settings            # 대회 설정 / 텍스트
/admin/participants        # 참가자 관리
/admin/teams               # 팀 편성
/admin/results             # 결과 집계
/api/auth/[...nextauth]    # next-auth 핸들러
/api/...                   # 도메인별 API (3장 참고)
```

## F1. 참가 신청 (Signup)

### 사용자 흐름

```
랜딩 페이지
  ↓ "참가 신청하기" 클릭
로그인 페이지 (비로그인 시)
  ↓ 카카오 로그인
참가 신청 폼 (/signup)
  ↓ 폼 제출
신청 완료 페이지 (/signup/complete)
  → 다음 단계: 입금 안내, 팀 배정 대기
```

이미 신청한 사용자가 `/signup`에 접근하면 `/signup/complete`로 자동 리다이렉트.

### 폼 필드

| 필드 | 타입 | 검증 | 비고 |
|---|---|---|---|
| `displayName` | string | min 1, max 20 | 본인 이름 (카카오 닉네임과 별개) |
| `mainGrade` | enum | 'red' \| 'pink' \| 'purple' | 평소 푸는 색 |
| `category` | enum | 'advanced' \| 'intermediate' \| 'beginner' | 카테고리 (자동결정 또는 사용자 선택) |
| `participantType` | enum | 'crew' \| 'guest' | |
| `agreedToTerms` | boolean | must be true | |

### 카테고리 결정 로직

```typescript
function getCategoryOptions(mainGrade: 'red' | 'pink' | 'purple'): {
  defaults: ('advanced' | 'intermediate' | 'beginner')[];
  selectable: boolean;
} {
  switch (mainGrade) {
    case 'purple': return { defaults: ['advanced'], selectable: false };
    case 'pink':   return { defaults: ['advanced', 'intermediate'], selectable: true };
    case 'red':    return { defaults: ['intermediate', 'beginner'], selectable: true };
  }
}
```

- 보라 → 상급 자동 고정 (선택 비활성화)
- 핑크 → 상급/중급 중 선택, 가이드 박스 표시
- 빨강 → 중급/초급 중 선택, 가이드 박스 표시

### 핑크/빨강 도전자 가이드

`contest_settings` 테이블에서 텍스트 가져옴:

- **핑크 → 상급**: `pink_guide_advanced` (예: "여러 지점에서 빨강을 한 세션에 절반 이상 풀 수 있어요")
- **핑크 → 중급**: `pink_guide_intermediate` (예: "빨강이 지점 따라 갈리고, 파랑은 무난해요")
- **빨강 → 중급**: `red_guide_intermediate` (예: "파랑을 한 세션에 무난히 풀 수 있어요")
- **빨강 → 초급**: `red_guide_beginner` (예: "파랑도 6개 지점 다 돌기는 부담스러워요")

### UI 컴포넌트

- 그레이드 선택: 색깔 카드 3개 (가로 배열, 그레이드 색 큰 점 + 이름)
- 카테고리 선택: 카드 2-3개 (세로 배열, 색 점 + 이름 + 설명 + 그레이드 라벨)
- 매핑 미리보기: 선택에 따라 동적으로 갱신 (예: "평소 핑크 → 대회에서 빨강")
- 약관: 체크박스 1개로 묶음 (개별 동의 X)
- 제출 버튼: 하단 sticky bar (모바일 한 손 도달)

### 서버 검증

```typescript
// /api/participants POST
1. 세션 확인 (next-auth)
2. Zod 스키마 검증
3. mainGrade × category 매핑 검증
   - purple는 advanced만 허용
   - pink는 advanced/intermediate
   - red는 intermediate/beginner
4. 동일 user_id로 이미 신청했는지 확인 (unique)
5. participants 테이블 insert
6. 성공 응답 + 리다이렉트 URL
```

## F2. 풀이 기록 (Input)

### 사용자 흐름

```
대시보드 또는 직접 진입
  ↓
/input 페이지
  ├ 상단: 본인 정보 + 진행률 (sticky)
  ├ 시간표 위젯 (접힘)
  ├ 지점 탭 (가로 스크롤)
  └ 벽 리스트 (선택된 지점)
       └ 각 벽: 카운터 (+/-, 직접입력)
```

### 상단 sticky 헤더

표시 정보:
- 본인 이름 + 카테고리 알약 + 팀명
- 본인이 푼 총 갯수 / 전체 갯수 (큰 숫자)
- 비율 % (액센트 색)
- 진행 바
- "대시보드 →" 버튼 (우측)

### 시간표 위젯

- 기본 접힌 상태
- 펼치면: 09:30 ~ 16:50 전체 일정 (시간 미정 시 "추후 공지" 표시)
- 현재 시각 + 다음 일정 한 줄 요약

### 지점 탭

- 6개 지점 칩 (가로 스크롤)
- 각 칩에 본인 진행 표시 (예: "신사 5/8")
- 활성 탭은 액센트 색
- 활성 탭은 자동 가운데 스크롤 (선택사항)

### 벽 카드

각 벽 카드에 표시:

- 벽 이름 (어드민 입력)
- 부제: "전체 빨강 N개" (본인 카테고리에 해당하는 그레이드)
- 우상단: 본인 완등률 % (작은 글자)
- 진행 바 (본인 비율)
- 카운터: [ − ] 큰 숫자 [ + ]
  - 버튼 크기 ≥ 56x56px
  - 숫자 직접 탭 → prompt로 직접 입력
  - − 버튼은 0이면 비활성 (회색)
  - + 버튼은 max 도달 시 비활성

### 자동 저장

- 입력 변경 → 300ms debounce → API 호출
- 호출 중: 작은 회전 아이콘 또는 "저장 중..."
- 성공: 녹색 점 + "저장됨" (2초 후 사라짐)
- 실패: 빨간 느낌표 + 재시도 버튼
- 페이지 하단: "자동 저장됨 · 방금 전" 항상 표시

### 검증

- 본인 카테고리에 맞는 그레이드만 입력 가능 (서버에서 검증)
- 입력값 ≤ 전체 갯수 (서버 + 클라이언트)
- 입력값 ≥ 0
- 카테고리 변경 시 (어드민이 변경한 경우) 기존 풀이 기록은 보존하되 화면에서 비활성화

### 어드민이 갯수를 줄였을 때

기존 풀이 기록이 새 max보다 크면:
- DB: 기존 값 유지
- UI: 빨간 경고 + "확인하고 수정해주세요" 안내
- 서버: 다음 입력 시 max로 자동 클램프

## F3. 대시보드 (Dashboard)

### 페이지 구조

```
┌─────────────────────────────┐
│ 공지 배너 (있을 때만)        │
├─────────────────────────────┤
│ 본인 카드 (Hero)             │
│  - 카테고리 알약              │
│  - 비율 % (큰 숫자)           │
│  - 부문 내 순위               │
│  - 진행 바                   │
│  - "풀이 기록하기 →" 버튼    │
├─────────────────────────────┤
│ 시간표 위젯 (접힘)           │
├─────────────────────────────┤
│ 카테고리 탭 (3개)            │
│  [상급] [중급] [초급]        │
├─────────────────────────────┤
│ 순위 리스트                  │
│  - 본인 행은 강조 (액센트)    │
│  - 게스트 뱃지                │
│  - 1~3위 메달 (🥇🥈🥉)        │
│  - 공동 순위 표시             │
├─────────────────────────────┤
│ 마지막 갱신 + 새로고침       │
└─────────────────────────────┘
```

### 카테고리 탭

- **상급**: advanced 카테고리 참가자만, 빨강 풀이 비율로 정렬
- **중급**: intermediate 카테고리 참가자만, 파랑 풀이 비율로 정렬
- **초급**: beginner 카테고리 참가자만, 초록 풀이 비율로 정렬

각 부문에서 비율 1위가 시상 대상. 부문 인원이 적어도(예: 초급 3명) 1위는 별도 시상.

### 순위 계산

```typescript
// 부문별로 별도 계산
function computeRanks(participants: Participant[]): Ranked[] {
  const sorted = [...participants].sort((a, b) => b.ratio - a.ratio);
  let lastRatio = -1;
  let lastRank = 0;
  return sorted.map((p, i) => {
    if (p.ratio !== lastRatio) {
      lastRank = i + 1;
      lastRatio = p.ratio;
    }
    return { ...p, rank: lastRank };
  });
}
```

동률 시: 같은 순위 부여 → 다음 순위는 인원수만큼 건너뜀 (예: 1, 1, 3 / 1, 2, 2, 4)

### 갱신 정책

- 페이지 마운트 시 1회 fetch
- 30초 자동 폴링 (`document.visibilityState === 'visible'`일 때만)
- "새로고침" 버튼 (수동)
- 풀이 입력 페이지에서 돌아왔을 때 자동 갱신

### 본인 강조

순위 리스트에서 본인 행:
- 배경: `#FEE2E2` (액센트 소프트)
- 테두리: 2px 액센트
- "나" 라벨 (좌상단 작은 뱃지)
- 폰트 굵게

## F4. 어드민 모드 (Admin)

### 진입 방식

```
참가자 헤더 (모든 페이지)
  └ 어드민 권한 보유 시: "어드민 모드" 토글 표시
       ↓ 토글 ON
  └ 어드민 메뉴 드롭다운 활성화
       ├ 지점/벽 관리
       ├ 시간 조정
       ├ 대회 설정
       ├ 참가자 관리
       ├ 팀 관리
       ├ 결과 집계
       └ 공지 입력 (즉시)
```

`localStorage`에 토글 상태 저장 → 페이지 이동 시 유지.

### A1. 지점/벽 관리 (`/admin/walls`)

- 지점 탭 (6개) — 클릭 시 해당 지점의 벽 리스트로
- 벽 카드 리스트:
  - 벽 이름 (편집 가능)
  - 빨강 갯수 / 파랑 갯수 / 초록 갯수 (각 그레이드별)
  - "비활성화" 버튼 (삭제 X, soft delete)
- "벽 추가" 버튼 (지점 하단)
- 변경 시 즉시 서버 반영 (debounce X, 명시적 저장 버튼 X — 입력 후 blur 시점)

### A2. 시간 조정 (`/admin/time`)

- 대회 일자: date picker
- 시작 / 종료 시각: time picker
- 점심 시작 시각 / 길이
- 지점별 체류 시간 (6개 지점 각각)
- 미리보기: 모든 팀의 도착/이동 시각 자동 계산해서 표시

### A3. 대회 설정 (`/admin/settings`)

- 대회 이름
- 참가비
- 도전 그레이드 정의문 (텍스트영역)
- 핑크 가이드 (상급/중급 각 1)
- 빨강 가이드 (중급/초급 각 1)
- 대시보드 공지 (단순 텍스트, 색상 옵션 X)
- 약관 본문

### A4. 참가자 관리 (`/admin/participants`)

리스트 항목당:
- 이름 + 카테고리 알약 + 크루/게스트 뱃지
- 입금 체크박스
- 어드민 권한 부여/회수 버튼
- 수정 / 삭제

검색 + 필터 (카테고리, 입금 여부, 크루/게스트).

### A5. 팀 관리 (`/admin/teams`)

- 팀 카드 리스트 (A팀, B팀, C팀…)
- 각 팀:
  - 이름 (편집 가능)
  - 멤버 (드래그앤드롭으로 추가/제거)
  - 각 지점에서 시작 벽 지정 (드롭다운으로 6개 지점 × 각 지점의 벽 중 1개)
- 미배정 참가자 별도 표시
- 배정 알고리즘 자동 추천 (선택사항): 카테고리별 균형 잡아 자동 분배

### A6. 결과 집계 (`/admin/results`)

대회 종료 후:
- 부문별 최종 순위
- 시상자 확정 버튼 (공동 1등 명시)
- CSV 다운로드 (이름, 카테고리, 푼 갯수, 비율)
- "결과 잠금" 토글 (이후 풀이 입력 막기)

### A7. 공지 입력

- 어떤 어드민 페이지에서도 접근 가능 (헤더 우상단)
- 텍스트 입력창 + 저장 버튼
- 저장 즉시 모든 참가자 대시보드에 노출 (다음 폴링 시점)
- 빈 값 → 배너 숨김

## 비기능 요구사항

### 모바일 우선 디자인

- 뷰포트: 360px (Galaxy 작은 폰) ~ 768px (태블릿) ~ 데스크탑
- 모든 터치 영역 ≥ 44x44px
- 한 손 조작: 주요 액션 화면 하단
- iOS safe-area-inset 대응 (`env(safe-area-inset-bottom)`)
- 시스템 폰트 fallback (Pretendard 로딩 전에도 깔끔)

### 접근성

- 충분한 색 대비 (텍스트 4.5:1, 큰 텍스트 3:1)
- 색깔만으로 정보 전달 X (그레이드는 색 + 이름 텍스트 같이)
- 키보드 네비게이션 가능
- 스크린리더 lang="ko"

### 에러 핸들링

- 네트워크 실패: 재시도 버튼 + 토스트
- 서버 에러: 사용자 친화 메시지 + 운영진 카톡 안내
- 401 → /login 리다이렉트
- 403 → 홈으로 리다이렉트
- 404 → 홈 링크와 함께 안내

### 로깅 / 모니터링

- Sentry 연동 (Free tier)
- 주요 이벤트 콘솔 로그 (개발 모드만)
- API 호출 시간 측정 (간단한 timing 로그)

## 향후 확장 (이번 버전 외)

- **시리즈화**: 매년 다른 지역으로 확장 (`tour_seasons` 테이블 추가)
- **소셜**: 결과 공유 카드 이미지 자동 생성
- **통계**: 본인 시간대별 페이스 그래프
- **푸시**: 브라우저 푸시 알림
- **PWA**: 오프라인 지원 + 홈 화면 추가
