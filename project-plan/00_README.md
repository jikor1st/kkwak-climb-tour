## 사용 흐름

1. **PRD 먼저 읽기**: 무엇을, 왜 만드는지
2. **기능 명세 + 데이터 모델 확인**: 무엇이 필요한지
3. **구현 단계로 진입**: 어떤 순서로 만들지

## 카테고리 매핑

> 본인 주력 난이도보다 1~2단계 낮은 그레이드를 풉니다.

| 평소 푸는 색 | 대회에서 풀 색 | 부문 |
|---|---|---|
| 보라 | 빨강 | 상급 |
| 핑크 | 빨강 | 상급 |
| 핑크 | 파랑 | 중급 |
| 빨강 | 파랑 | 중급 |
| 빨강 | 초록 | 초급 |

핑크 도전자는 상급/중급 중 본인 양심껏 선택. 빨강 도전자는 중급/초급 중 선택.

## 더클라임 그레이드 (쉬움 → 어려움)

하양 → 노랑 → 주황 → 초록 → 파랑 → 빨강 → 핑크 → 보라 → 회색

## 기술 스택

```
Frontend:   Next.js 14 (App Router) + TypeScript + Tailwind CSS
Backend:    Next.js API Routes (Route Handlers)
Auth:       next-auth v5 (Auth.js) + Kakao Provider
Database:   Supabase (Postgres)
배포:        Vercel + Supabase (모두 무료 플랜)
상태관리:    Zustand
폼:          React Hook Form + Zod
```

## 구현 우선순위 (한 줄 요약)

1. 인프라 셋업 (프로젝트 + DB + 카카오 OAuth)
2. 참가 신청 흐름
3. 풀이 기록 흐름
4. 대시보드 (순위 + 본인 진행)
5. 어드민 모드 (지점/벽/시간/텍스트 관리)

자세한 내용은 `04_IMPLEMENTATION_PHASES.md` 참고.
